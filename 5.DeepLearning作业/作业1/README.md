### Deep Learning学习记录

在跟着直播课学习之前我已经学习过了黑马程序员的深度学习课程，net.py的构建是基于黑马程序员的课程的cnn图像分类案例来实现的，使用了最基础的cnn网络结构，包括卷积层、池化层、全连接层。
cnn_net.py是黑马程序员课上的以torchvision自带的CIFAR10数据集为例的深度学习案例。

net是我在提供的模版上设计的神经网络，它比较基础，用了八层神经网络，包括卷积层1、卷积层2、卷积层3、卷积层4、全连接层1、全连接层2、全连接层3、输出层。

enhanced_net.py是我借助AI对我的神经网络进行的增强：
1. 用了12层神经网络，包括卷积层1、卷积层2、卷积层3、卷积层4、全连接层1、全连接层2、全连接层3、输出层，
2. 用了预训练参数模型，让这个一千多张图的小样本训练也能得到比较好的效果。
3. 进行了数据增强，包括旋转、平移、缩放、翻转等操作，增加数据集的多样性。
4. 把批大小从1024改成64，防止内存溢出。
5. 自动调节学习率，防止过拟合。
6. 把SGD改成了Adam。
